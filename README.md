## 👨‍💻 About Me

🎓 I'm a **Computer and Systems Engineering student at NED University of Engineering & Technology**, passionate about understanding how hardware and software work together.

🔹 Designing digital circuits and processor control units.  
🔹 Exploring RISC-V architecture using Logisim and HDL-based design.  
🔹 Practicing Verilog and SystemVerilog with AMD Xilinx Vivado.  
🔹 Building AI-powered applications using Python, FastAPI, and RAG.  
🔹 Exploring cloud computing, Docker, Kubernetes, and CI/CD.

💡 **My goal:** To build practical engineering projects that connect computer architecture, digital hardware, embedded systems, and intelligent software.
